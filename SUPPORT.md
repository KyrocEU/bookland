# Bookland support

Bookland is a free, open-source preview maintained on a best-effort basis. Start
with the [README](README.md) for installation, features, and current limits, or
the [troubleshooting guide](docs/TROUBLESHOOTING.md) for common setup problems.

## Choose the right place

- **A first impression or question:** use the [first-look discussion](https://github.com/KyrocEU/bookland/discussions/2).
  Watching the real Mac demo is enough to leave feedback; you do not need to
  install the app.
- **An idea:** open a [first-look feedback issue](https://github.com/KyrocEU/bookland/issues/new?template=first-look.yml)
  and describe the action you wish Bookland could do. One concrete example is
  more useful than a long feature list.
- **A reproducible bug:** use the [bug report form](https://github.com/KyrocEU/bookland/issues/new?template=bug-report.yml).
  Include the Bookland release, Mac model, macOS version, exact steps, and the
  player or browser if music is involved.
- **A code contribution:** read [CONTRIBUTING.md](CONTRIBUTING.md) and open an
  issue before a large change.

Do not post private calendar entries, account names, API keys, or unredacted
logs and screenshots in public issues or discussions. Keep details of a
potential security vulnerability private; the project does not yet have a
dedicated private vulnerability reporting channel.
