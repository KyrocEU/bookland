# Bookland security

If you believe you found a security vulnerability in Bookland, please use
the **Report a vulnerability** button on [Security Advisories](https://github.com/KyrocEU/bookland/security/advisories).
Include the affected version, steps to reproduce, and the impact. Keep proof
of concept data private and remove personal information from logs or captures.

Bookland is a volunteer-maintained open-source preview. We will review reports
as time permits and coordinate a fix and disclosure with the reporter. For
ordinary bugs or feature ideas, use the [public issue forms](https://github.com/KyrocEU/bookland/issues/new/choose).
