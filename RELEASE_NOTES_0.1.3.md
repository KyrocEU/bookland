# Bookland 0.1.3 preview

This update makes the island's horizontal media gestures agree with its visible controls. In supported browser media sessions, a swipe seeks 15 seconds backward or forward. In Apple Music and Spotify, it changes tracks. The Behavior settings now explain the difference.

Bookland remains a free, open-source preview for Apple Silicon Macs running macOS 26 or later. This ZIP is locally signed with the same Bookland identity as 0.1.2; it is not Apple-notarized. macOS may require **System Settings → Privacy & Security → Open Anyway** after the first launch attempt. Verify the ZIP with the companion SHA-256 file.

The [README](README.md) lists features, installation steps, and current limits. In particular, approvals raised by turns already running in Codex Desktop cannot yet be answered inside Bookland; Bookland-connected turns can show their own approvals in the island.
