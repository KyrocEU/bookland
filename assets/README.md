# Codex activity mark

Bookland's original app icon and island-menu mark are documented in [brand/README.md](brand/README.md).

`openai-blossom-white.png` is a 96×96 copy of the OpenAI Blossom from the [official OpenAI logo download](https://cdn.openai.com/brand/openai-logos.zip), retrieved 23 November 2026. Transparent margins were cropped before resizing. OpenAI owns the mark. Bookland uses it only to identify Codex activity and is not an OpenAI product.

`notch-shoulder-left.png` and `notch-shoulder-right.png` are original opaque-black
RGBA masks generated by `generate_notch_shoulders.py`. Their transparent edges
round the outside of the closed island; Bookland fills the center solid black.
